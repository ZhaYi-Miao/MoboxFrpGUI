**MoboxFrpGUI** 是一款专为 Windows 设计的现代化内网穿透客户端。它集成了强大的 `frpc` 内核，拥有完美适配 Windows 11 的视觉界面，致力于提供“一键式”的内网穿透体验

**温馨提示**: 该软件对于 `3**安全卫士` 、 `2***安全卫士` 、 `金***` 、 `Windows Defender` 等杀毒软件建立了单向合作关系，如果遇到报毒添加白名单或者关闭杀毒软件即可

目前版本未加入 `节点列表` 、 `每日签到` 等功能，如有需要请前往官网：https://www.moboxfrp.top

## ✨ 项目特色

- **🎨 极简美学**：基于 `ModernWPF` 深度定制，支持原生深色模式，视觉效果与系统无缝融合
- **🔌 核心自释放 (Embedded)**：内核 `frpc.exe` 嵌入在程序内部，首次启动自动释放至 `Resources` 目录，无需手动下载
- **📦 灵活版本选择**：
  - **Light 版 (Single EXE)**：37MB 极致便携，适合已安装 .NET 8 环境的用户
  - **Full 版 (Standalone ZIP)**：内置完整运行时，解压即用，适合所有 Windows 环境
- **🛡️ 纯净安全**：经过多语言过滤优化，杜绝冗余 DLL，代码开源透明，受 GPL-3.0 协议保护

## 🚀 快速开始

### 下载
前往 [Releases 页面](https://github.com/ZhaYi-Miao/MoboxFrpGUI/releases) 获取：
1. **追求极致便携**：下载 `MoboxFrpGUI_v1.0.0.exe`
2. **追求绝对稳定**：下载 `MoboxFrpGUI_v1.0.0_Full.zip`（推荐，内置所有环境）

### 使用
1. 运行 `MoboxFrpGUI.exe`
2. 软件会自动在同级目录生成 `Resources` 文件夹并准备好内核
3. 输入你的隧道配置信息，点击开启即可
